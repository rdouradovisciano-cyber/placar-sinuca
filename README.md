# Placar de Sinuca

Placar e relatórios de sinuca/bilhar (PWA). Dados salvos no navegador.

## Funcionalidades
- Partida ao vivo com placar em tela dividida (modo live)
- Relatórios por período, tipo de jogo e adversário
- Histórico com edição e exclusão
- Backup (exportar/importar JSON e CSV)
- Temas de cores personalizáveis (presets + cores customizadas)
- Funciona offline (PWA) e instalável no celular

## Como usar
Abra o `index.html` em um navegador moderno ou publique a pasta em qualquer host estático.

## Desenvolvimento
Projeto estático (HTML/CSS/JS). Sem build necessário.
